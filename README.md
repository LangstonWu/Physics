# Physics Pro - HKDSE Study Assistant

An interactive web application for 15-year-old students studying HKDSE Physics.

## Features

- **Interactive Slides**: Step-by-step notes with diagrams and formulas
- **Digital Flashcards**: Flip cards for key concepts and definitions
- **Practice Questions**: 100+ MCQs per chapter with explanations
- **Progress Tracking**: Monitor learning progress across topics
- **Responsive Design**: Works on desktop, tablet, and mobile

## Topics Covered

1. **Mechanics**: Motion, forces, energy, momentum
2. **Heat**: Temperature, heat transfer, gas laws
3. **Waves**: Wave properties, sound, light
4. **Electricity**: Circuits, current, voltage, power
5. **Magnetism**: Magnetic fields, electromagnetism
6. **Atomic Physics**: Radioactivity, nuclear reactions
7. **Space Physics**: Gravity, orbits, astronomy

## How to Use

1. Clone or download the project files
2. Open `index.html` in any modern web browser
3. Click on any topic card to start learning
4. Use the tabs to switch between slides, flashcards, and quizzes
